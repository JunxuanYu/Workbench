# 这是一个个人工作台项目
直接点击start.bat 运行即可。

# 首页预览
由今日计划、开发工作、咨询工作、饮食计划、账目计划组成。
可预览各项功能的概要，并提供导航链接。

# 今日计划
可在上方对话框快捷添加事件，并可以选择时间范围。

# 开发工作
可新建项目，记录该项目的进度，分为待办、进行中、已完成三部分。可以通过点击任务框右侧箭头移向下一个状态，也可以自行拖拽。

# 咨询工作
管理客户、每次咨询的记录、客户相关待办与费用。

# 账目计划
记每一笔收支，月底知道钱花哪了、结余多少。
设有收入表、支出表、预算表、结余表，支出分布图，预算进度图，让我们清楚每项支出。在记一笔中，我们可以选择支出的类型和收入类型，做好分类。

# 饮食计划
记录每天吃了什么，今天漏没漏顿一眼看出

# 数据与设置
密码箱：加密存储密码、密钥等重要信息（PBKDF2+AES-GCM，本地文件不含明文）。
工作台外观：白色 / 黄色 / 蓝色 / 奶油色 四套配色，选择即生效并自动保存。
备份、恢复、清空数据，管理账目分类。
可添加账目分类
左侧栏底部「关闭工作台」按钮：关闭服务并退出（若浏览器阻止则提示手动关闭）。
