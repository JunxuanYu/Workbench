## 1. 技术选型与运行方式

| 项 | 决策 | 理由 |
|---|---|---|
| 运行时 | Node.js（已安装）+ Python 3.10+（PDF 转换用） | Node 本机可用；Python 首次运行由 start.bat 自动建 venv |
| 后端 | Express + 原生 Node http | 仅需静态文件 + 数据读写，最小依赖 |
| 前端 | 原生 HTML/CSS/JS 单页应用（hash 路由） | 无构建步骤、无外部CDN → 保证"断网可用"（PRD §7） |
| 数据存储 | 单个 JSON 文件 `data/worklift-data.json` | 符合"数据在一个文件中"；备份=复制该文件 |
| 保存方式 | 每次操作 PUT 整个数据对象，服务端**原子写入**（先写临时文件再重命名） | 满足"即时保存、刷新/关闭/重启不丢" |
| 端口 | 8787，仅绑定 127.0.0.1 | 只本机访问，不暴露局域网 |
| 启动 | `start.bat` → 检查/准备 Python venv → `node server.js` → 服务启动后**自动用默认浏览器打开** http://127.0.0.1:8787 | 双击即用 |
| 依赖 | npm 仅 `express`；Python 依赖（PyMuPDF/python-docx/openpyxl/python-pptx）装在 `python/.venv` | 最小化、不污染全局 |
| 测试 | `npm test`（`node --test`）+ `python\.venv\Scripts\python -m unittest`（python/tests） | 纯逻辑函数模块化，Node/Python 下直接可测 |

**例外**：PDF 转换调用本机 Python（`python/pdf_convert.py`，PyMuPDF 等）子进程，产出**真实格式**（.docx/.xlsx/.pptx/.zip/.txt）；仅首次运行 `start.bat` 需要联网安装 Python 依赖，之后完全离线可用（不再依赖任何 CDN）。

## 2. 当前功能清单（已实现）

### 首页总览（pages/home.js）
- 顶部：今天日期 + "今天 X 件事，完成 Y 件"（含顺延项）
- 5 张摘要卡片（今日计划/开发工作/工具箱/个人笔记/账目计划）：
  - 每卡显示关键数字，**点击卡片跳转到对应模块**
  - 每卡带"概要内容"列表（今日待办前3条、进行中任务、工具名单、最近笔记标题、最近账目），可直接点击跳转
- 快速备忘：添加、⭐置顶、**编辑**、删除；**可设提醒日期（可选）+ 提醒时间（可选）**，到期标红

### 今日计划（pages/today.js）
- 表格式添加：内容、日期（必填）、**开始/结束时间（可选，HH:mm，可只填一端）**、重要、备注
- 勾选完成（沉底）、取消完成；⭐重要；✏编辑（含时间段、备注、关联文档）；🗑删除（确认框）
- 日期切换 ◀▶ + 弹日历 + "回到今天"
- 标签筛选：全部 / 今天 / 明天 / 逾期
- 逾期自动顺延："今天"视图合并未完成过期项，标"昨·未完成（原X月X日）"
- **拖拽排序**：未完成项可拖拽重排，按新的展示顺序持久化各源日期的顺序（跨日期也可）
- **关联文档**：任务可挂网页链接与本地文件/文件夹路径（多行文本，`标题|链接` 格式），本地路径由服务端 `/api/open` 调系统默认程序打开
- 空状态引导文案

### 开发工作（pages/dev.js）
- 左栏项目列表（显示"待办X · 进行中X"），**项目可拖拽排序**
- 新建/编辑/删除项目：**项目可填远程仓库链接（http(s)，自动补协议）**，项目头显示"🔗 远程仓库"按钮新标签页打开
- 右侧三栏看板：待办 / 进行中 / 已完成
  - "→"按钮推下一栏（done 不往后推）
  - **任务拖拽移动/排序**：跨栏拖或同栏重排，落点自动定位（order 字段持久化）
  - 任务展开编辑：标题/优先级/备注/**关联文档**（同今日计划格式）
  - **每个任务独立的删除按钮**（确认框）
- 工作日志：日期（默认今天）+ 内容 + 耗时，新在上，可删除

### 工具箱（pages/consult.js + tools/，原"咨询工作"重构）
- **通用工具注册框架**：`registerTool({id, name, icon, render})` 左栏工具列表 + 右栏渲染区，新增工具只需注册（见 `tools/pdf-convert.js` 实现范式）
- 内置工具：
  - **📑 PDF 转换**（tools/pdf-convert.js + python/pdf_convert.py）：PDF → Word(.docx) / 图片(.zip，逐页预览下载) / Excel(.xlsx) / PPT(.pptx) / TXT；Node 子进程调用本机 Python（PyMuPDF/python-docx/openpyxl/python-pptx）产出真实格式，完全离线（无 CDN）；上传会话令牌 60 分钟有效，临时文件存 `data/.pdf-tmp/` 并定时清理
  - **📝 Markdown 转换**（tools/md-convert.js + python/md_convert.py）：Markdown → PDF，保留标题/加粗/列表/表格/代码块，中文正常，完全离线
  - **🔧 JSON 转换**（tools/json-convert.js）：格式化 / 压缩 / 校验（含行列定位）/ 转 CSV / 转 YAML，结果可下载
- 注：原"咨询工作"客户管理功能已移除（`clients` 数据字段保留以兼容旧数据文件，无 UI）

### 个人笔记（pages/notes.js + markdown.js）
- 上传 `.md` / `.markdown` / `.txt`（单文件 ≤ 1MB），读取文本存入 `state.notes`
- 标题取正文首个 H1；无 H1 时回退文件名/“未命名笔记”
- 左栏笔记列表（按创建时间倒序）+ 删除确认；右侧 Markdown 正文
- H1 目录侧栏（窄屏置顶）：`slugifyHeading` 生成锚点，重复标题自动加序号；点击平滑滚动
- `renderMarkdown` 安全渲染：先整体 HTML 转义，再生成标题/列表/代码/表格/引用/链接；`safeUrl` 拒绝 `javascript:` 等危险协议，不渲染原始 HTML/图片
- 固定使用 `.notes-layout/.notes-sidebar/.notes-article/.markdown-body` 样式，已接入桃夭主题变量
- 首页笔记卡显示总数与最近 3 条标题

### 账目计划（pages/money.js）
- 月份切换（◀ 2026年9月 ▶）
- 顶部四卡：本月收入 / 本月支出 / **本月预算** / 本月结余
- "＋ 记一笔"：支出/收入 → 金额 → 分类（支出显示支出类、收入显示收入类）→ 日期（默认今天）→ 备注
- **月度预算**：设置/修改预算金额（0 取消）；预算进度条（已用/剩余百分比，超支标红）
- **支出分布环形图**（conic-gradient，按类别占比）+ 类别条形排行（本月支出 top6，最长排最上）
- 明细列表（日期倒序）：筛选 全部/支出/收入/分类；每行可编辑、删除

### 数据与设置（pages/settings.js + vault.js + theme.js + close-workbench.js）
- **🎨 工作台外观**：13 套主题配色，默认「桃夭」；另含白/黄/蓝/奶油 + 国风系列（中国红/青瓷/墨韵/琉璃/竹青/藕荷/脂玉/天青），选择即生效并自动保存（`state.settings.theme`）
- **🔐 密码箱**（vault.js）：
  - PBKDF2 派生密钥 + AES-GCM 加密，密文存数据文件，**本地文件不含明文**
  - 设置主密码（≥6位）/ 解锁 / 锁定 / 修改主密码
  - 条目：名称/账号/密码密钥/备注，增删改；明文仅存内存，**切换页面自动锁定**
- 数据文件信息卡：位置（绝对路径）、大小（KB）、上次保存时间
- 备份：一键下载 `WorkLift备份-YYYY-MM-DD.json`
- 恢复：选备份文件 → 校验 JSON → 警告输入"确认" → PUT 覆盖
- 清空全部数据：两次确认（弹窗 + 输入"确认"）
- 账目分类管理：**分类带用途标签（支出/收入/通用）**；默认分类不可删；已被账目使用的自定义分类不可删
- 侧边栏底部「⏻ 关闭工作台」按钮：POST `/api/shutdown` 关闭服务并退出

## 4. 数据模型（data/worklift-data.json）

```jsonc
{
  "version": 1,
  "updatedAt": "2026-09-11T...",

  "vault": null,                   // 🔐 密码箱（加密结构：salt/iterations/data，内容为密文）
  "settings": { "theme": "peach" },// 🎨 工作台外观（主题键，13 选一，默认桃夭）

  "memos": [                       // 快速备忘（首页）
    { "id": "m1", "text": "记得交房租", "pinned": true,
      "date": "2026-09-15", "time": "18:00",   // 提醒日期（可选）+ 提醒时间（可选）
      "createdAt": "..." }
  ],

  "plans": {                       // 今日计划：键=日期 YYYY-MM-DD
    "2026-09-11": [
      { "id": "p1", "text": "上午改完首页", "done": false,
        "important": true, "note": "", "origDate": "2026-09-10",
        "timeStart": "09:00", "timeEnd": "11:00",  // 时间段（可选，可只填一端）
        "links": [ { "title": "PRD", "url": "D:\\Blogs\\WorkLiftApp\\docs\\PRD.md" } ] }  // 关联文档（可选）
    ]
  },

  "projects": [                    // 开发工作
    { "id": "pr1", "name": "WorkLift", "desc": "",
      "repoUrl": "https://github.com/user/repo",   // 远程仓库链接（可选，归一化 http(s)）
      "tasks": [
        { "id": "t1", "title": "首页设计", "status": "doing",  // todo|doing|done
          "priority": "important", "note": "",
          "order": 0,               // 同栏拖拽排序序号
          "links": [] }             // 关联文档（可选）
      ],
      "logs": [                    // 工作日志
        { "id": "l1", "date": "2026-09-11", "content": "做了首页设计", "hours": "2小时" }
      ] }
  ],

  "clients": [],                   // 原"咨询工作"数据字段（保留兼容旧文件，无 UI 使用）

  "notes": [                       // 📝 个人笔记（v1.1）
    { "id": "n1", "title": "读书笔记",
      "content": "# 读书笔记\n\n正文 Markdown...", "createdAt": "2026-10-24T..." }
  ],

  "ledger": [                      // 账目计划
    { "id": "e1", "type": "expense", "amount": 35,  // expense|income
      "category": "餐饮", "date": "2026-09-11", "note": "午餐" }
  ],

  "budgets": { "2026-09": 2000 },  // 月度预算：键=YYYY-MM，值=金额（无此月键=未设置）

  "categories": [                  // 账目分类（kind: expense支出|income收入|both通用）
    { "name": "餐饮", "kind": "expense", "builtin": true },
    { "name": "工资收入", "kind": "income", "builtin": true }
    // 自定义分类：{ "name": "xxx", "kind": "both", "builtin": false }
  ]
}
```

**关键实现规则**
- 所有日期用本地日期字符串 `YYYY-MM-DD`（不用UTC，避免时区差一天）。
- **逾期顺延是"算出来的视图"，不改存储**：看"今天"时，取今天的任务 + 所有 `origDate < 今天 && !done` 的任务；"逾期"标签 = 所有 `date < 今天 && !done`。
- 原子保存：服务端把新数据写 `worklift-data.json.tmp` → 成功后重命名覆盖原文件。
- 服务端校验：PUT 前检查合法 JSON、`version`、各数组/对象字段形状；非法 400 且不写文件。`vault`/`budgets`/`settings`/`notes` 为**可选字段**（兼容旧数据）。
- 数据迁移：`migrateData()` 在读取时删除旧 `meals` 字段、补全 `notes: []`，并保证 `settings.theme` 为合法主题；不修改磁盘旧文件，直到下次保存。
- 链接归一化（`logic.js`）：http(s) 链接自动补 `https://`，非法协议（ftp:// 等）拒绝；本地路径支持盘符 `C:\`、UNC `\\server`、POSIX `/`；解析失败返回行号错误提示。
- 主题非法键自动回退默认 `peach`（`normalizeTheme` / `THEME_DEFAULT`）。
- Markdown 安全：`renderMarkdown()` 先对全文转义，再生成受控标签；`safeUrl()` 仅允许 http(s)/mailto/站内锚点，禁止 `javascript:`/`data:` 等协议，不渲染原始 HTML。
- 分类下拉：支出显示 `kind` 为 expense/both 的分类，收入显示 income/both；默认分类合计 7 个（6 支出 + 1 收入）。
- 密码箱：PBKDF2（salt+iterations）+ AES-GCM；`vault.data` 为密文按条目加密的数组。明文只存在于解锁会话内存，切换 hash 路由即清空。

## 5. API 设计（server.js）

| 接口 | 方法 | 说明 |
|---|---|---|
| `/`、`/index.html`、`/css/*`、`/js/*` | GET | 静态文件（前端资源）；body 上限 10mb |
| `/api/data` | GET | 返回整个数据对象 |
| `/api/data` | PUT | 接收整个数据对象，校验后原子保存；成功 `{ok:true}` |
| `/api/backup` | GET | 附件下载，文件名 `WorkLift备份-YYYY-MM-DD.json` |
| `/api/info` | GET | 数据文件信息：`{filePath, size, updatedAt}` |
| `/api/open` | POST | body `{path}` 调系统默认程序打开本地文件/文件夹（关联文档用） |
| `/api/shutdown` | POST | 关闭 Web 服务并退出进程（「关闭工作台」按钮用） |
| `/api/ping` | GET | `{ok:true}`（启动自检） |

## 7. 后续开发注意事项

- **端口冲突**：8787 被占用时 `server.js` 打印明确错误并提示改端口（改一处常量即可）。
- **原子写失败**：磁盘满等极端情况保留原文件并返回 500，前端 toast 提示"保存失败，请重试"。
- **时间与日期**：一律用本地日期 `YYYY-MM-DD`；勿用 `toISOString()`（UTC 可能差一天）。
- **断网**：除第一次运行 `start.bat` 安装 Python 依赖外，其余全部本地资源，断网可用（PDF 转换已从 CDN pdf.js 迁到本机 Python）。
- **中文文件名备份**：`Content-Disposition` 需 `filename*=UTF-8''...` 编码，否则中文名乱码。
- **新增功能流程**：新增纯逻辑先写进 `logic.js`（或独立 tools/vault 模块）→ 写对应 `test/*.test.js` → 页面调用。保持"纯逻辑不依赖 DOM、Node 可测"。
- **新增工具箱工具**：在 `public/js/tools/` 建文件，实现 `createXxxTool() { return { id, name, icon, render } }`，在 `consult.js` 注册即可，无需改路由/导航。
- **数据兼容**：`validateData` 中 `vault`/`budgets`/`settings`/`clients`/`notes` 均为可选字段——新增顶层字段时沿用此模式，避免旧数据文件校验失败。
- **旧数据迁移**：读取入口统一走 `migrateData`（前端 store 与服务端 readData）；删除字段时保留迁移清洗，不要求用户手动改 JSON。
- **安全回归**：新增 Markdown/HTML 渲染或文件路径入口时，必须补充 `test/security.test.js` 用例（XSS、危险协议、路径穿越、未授权 API）。
- **不要做**：任何未在本文档与 PRD §9 之外扩展的功能，先补文档再开发。
