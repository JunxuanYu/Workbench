## 功能变更：开发工作页面为任务添加删除按钮

### 变更概要

在「开发工作」页面的三栏任务看板中，每张任务卡片新增「🗑️ 删除」按钮。点击后弹出危险操作确认框（防误删），确认后该任务从项目中删除并持久化保存；删除不会影响同列其余任务的相对顺序。任务卡片上原有的「→」状态流转与「点击卡片编辑」交互保持不变。

| 文件 | 变更类型 | 说明 |
|------|----------|------|
| `public/js/logic.js` | 修改 | 新增纯函数 `deleteTask(project, taskId)`：从项目的 `tasks` 数组中移除指定任务，返回 `{ changed }` |
| `public/js/pages/dev.js` | 修改 | 导入 `deleteTask`；在 `taskRow` 中新增「🗑️」删除按钮，复用 `confirmDialog` 危险确认弹窗，确认后 `mutate` 删除并重新渲染 |

### 功能说明

#### 交互方式

- 每张任务卡片右侧新增「🗑️」图标按钮（与工作日志删除按钮同一风格 `.btn-icon`），悬停提示「删除任务」。
- 点击后弹出红色危险确认框「确定删除任务「XXX」吗？」，点「删除」才生效，点「取消」或遮罩关闭即放弃。
- 删除按钮自带 `stopPropagation`，不会误触卡片进入「编辑任务」弹窗；与「→」状态流转按钮行为一致。
- 删除后出现「已删除」提示，看板重新渲染；数据经 `mutate` 自动持久化，刷新/重启后不恢复。

#### 实现方式

- **`deleteTask(project, taskId)`**：在项目 `tasks` 数组中按 `id` 查找并 `splice` 移除；其余任务保持原顺序与内容不变，不重排 `order`（列内排序按相对值比较，删除留下的空隙不影响展示；下次拖拽移动时会自动重新编号）。任务不存在、`tasks` 为空或 `project` 为空时返回 `{ changed: false }` 且不做任何修改，保证重复点击/异常数据下的安全性。
- **删除按钮**：插入在「→」按钮之后，onclick 内 `e.stopPropagation()` → `await confirmDialog({ danger: true })` → 确认后 `mutate` 内调用 `deleteTask`。
