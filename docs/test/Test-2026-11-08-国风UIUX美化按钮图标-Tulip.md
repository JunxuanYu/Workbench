# 测试报告 - 国风 UI/UX 精修（按钮 · 图标美化）

**日期**: 2026-11-08
**事项**: 设计国风 UI/UX，美化项目的按钮、图标等元素（仅外观，零功能改动）
**执行人**: Tulip

> 背景：v1.3 已具备"桃夭"国风主题底座（桃粉胭脂 + 暖白宣纸 + 细描边）。
> 本轮在该底座上进行第二轮**国风精修**，聚焦两个最常暴露在用户视野中的元素层——
> **按钮**与**图标**，并全部以"纯样式层"方式落地，不触碰任何 DOM 结构、事件与数据流。

---

## 一、改动内容（纯外观层）

### 1. 图标：篆印导航图标（本轮核心）

| 位置 | 改动 | 效果 |
| --- | --- | --- |
| 侧栏导航（`public/index.html`） | 7 个 emoji 图标（🏠📋💻🧰📝💰⚙️）换为**印章汉字**：览 / 计 / 匠 / 具 / 笔 / 账 / 设 | 去emoji化图标体系更贴合国风设计语言 |
| `.nav-icon`（样式层） | 汉字渲染为 26px **篆印小方章**：宋体系衬线字体 + 印边随主题强调色描色 + 内白高光 + 悬浮轻抬 | 图标具备"朱印"质感，且随 13 套主题自适应变色 |
| 激活态印章 | 当前页印章为**朱砂渐变底 + 白字**（`linear-gradient(160deg, #d37a8e → var(--accent-dark))`） | 导航选中一目了然，国风氛围统一 |
| 关闭按钮图标 | `⏻` 换为国风字 **「阖」**（描边小方印样式） | 与印章体系呼应 |
| 日期导航图标 | `📅`（CSS content）换为 **「历」**（主题强调色、加粗） | 去 emoji 化，国风字符点缀 |

### 2. 按钮：朱砂质感

| 元素 | 改动 |
| --- | --- |
| `.btn`（全部按钮） | 字距 0.03em + `inset` 顶部 1px 高光（宣纸内衬感） |
| `.btn-primary` / `.btn-danger` | 新增**釉面高光层**（`::after` 半透明白色渐变 + `pointer-events: none`，不拦截点击）、主按钮顶部渐变高光与文字阴影、禁用态自动关闭釉面 |
| `.btn-icon` | hover 增加**描金内环**（主题强调色 `inset` 描边） |
| `.tab` | 激活标签增加顶部釉面（同样 `pointer-events: none`） |
| 原生控件 | 复选框/单选框/滑块 `accent-color: var(--accent)`，随国风主题统一着色 |

> 关键防呆：所有装饰层均设 `overflow: hidden` + 圆角继承 + `pointer-events: none`，
> 视觉无论如何堆叠都不会阻挡点击或拖拽操作。

### 3. 明确不改动（功能零影响承诺）

- 未改任何 JS 逻辑文件（路由/数据/事件/工具全部原样）；
- 未改导航 DOM 结构、`data-route`、路由文案；
- 设置页的 13 套主题机制、外观选择器照常工作；
- `md-convert` 等处 emoji 图标未动（有测试锁定）；
- `prefers-reduced-motion` 与窄屏适配继续生效。
