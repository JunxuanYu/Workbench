# WorkLift — 个人工作台

一个只给自己用的本地"工作 + 生活"管理工具：计划、开发项目、小工具、个人笔记、花钱、密码，全部记在一个文件中。
双击 `start.bat` 运行，自动打开浏览器进入。数据保存在本机，断网可用。

## 模块功能

# 首页总览
- 一眼看全局：今天几件事、项目进度、工具、笔记、花钱
- 5 张摘要卡片，每张含概要内容，点击卡片/概要可跳转到对应模块
- 快速备忘：置顶、可设**提醒日期与提醒时间**（到期标红）、编辑、删除

# 今日计划
- 表格式快捷添加：内容 + 日期 + **开始/结束时间（可选）** + 重要 + 备注
- 勾选完成（沉底）、⭐重要、编辑、删除
- 日期切换（◀▶ / 日历 / 回到今天）
- 筛选：全部 / 今天 / 明天 / 逾期
- 逾期任务自动顺延到今天，标记"昨·未完成（原X月X日）"
- **拖拽排序**、任务可挂**关联文档**（网页链接或本地文件路径）

# 开发工作
- 项目列表（新建/编辑/删除，**可拖拽排序**）
- 项目可填**远程仓库链接**，一键跳转
- 任务三栏看板：待办 / 进行中 / 已完成
  - "→"按钮推送下一状态，或**拖拽跨栏/重排**
  - 任务可展开编辑（标题/优先级/备注/关联文档），独立删除按钮
- 工作日志：日期 + 干了啥 + 耗时，可删除

# 工具箱
- 通用工具注册框架，按需扩展新工具
- **PDF 转换**：PDF → Word / 图片 / Excel / PPT / TXT / Markdown（本机 Python 转换，产出真实格式，完全离线）
- **Markdown 转换**：Markdown → PDF（标题/加粗/列表/表格/代码块等排版，中文正常，完全离线）
- **JSON 转换**：格式化 / 压缩 / 校验 / 转 CSV / 转 YAML，可下载结果

# 账目计划
- 按月记账，月份切换
- 四卡：本月收入 / 本月支出 / **本月预算** / 本月结余
- **月度预算**设置，进度条显示已用/剩余，超支标红
- **支出分布环形图** + 类别条形排行
- 明细筛选：全部 / 支出 / 收入 / 分类；每笔可编辑、删除

# 个人笔记
- 上传 `.md` / `.markdown` / `.txt` 笔记（单文件 ≤ 1MB），本地保存
- 标题自动取正文首个 H1，无 H1 时回退文件名
- 安全渲染 Markdown：标题/列表/表格/代码块/引用/链接，HTML 全部转义
- 右侧 H1 目录（窄屏置顶），点击平滑滚动，重复标题自动生成唯一锚点
- 笔记列表切换、删除确认；首页显示笔记总数与最近标题

# 数据与设置
- **🔐 密码箱**：加密存储密码、密钥等重要信息（PBKDF2+AES-GCM，本地文件不含明文）；设置/解锁/修改主密码，切页自动锁定
- **🎨 工作台外观**：13 套配色，默认「桃夭」桃粉国风；另有白色/黄色/蓝色/奶油色 + 国风系列，选择即生效并自动保存
- 数据文件信息（位置/大小/上次保存）、一键备份、从备份恢复、清空全部数据（双重确认）
- 账目分类管理（支出/收入/通用标签，默认分类不可删）
- 左侧栏底部「关闭工作台」按钮：关闭服务并退出

## 技术
- Node.js + Express（仅一个 npm 依赖），原生 HTML/CSS/JS 单页应用
- PDF / Markdown 转换调用本机 Python（PyMuPDF 等）子进程：需要 Python 3.10+，首次运行 `start.bat` 会自动创建虚拟环境并联网安装依赖，之后完全离线可用，临时文件自动清理
- 数据：单个 JSON 文件，变化即原子保存
- 测试：`npm test`（node --test）+ `python -m unittest`（python/tests）
- 详细架构与数据模型见 [docs/开发计划.md](docs/开发计划.md)，需求依据见 [docs/PRD.md](docs/PRD.md)，文档索引见 [docs/README.md](docs/README.md)
