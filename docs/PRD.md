> 凡本文档未提及的功能，一律不属于当前范围；新增需求先更新本文档再开发。

## 1. 产品目标和使用场景

**产品目标**
做一个只给自己用的"工作 + 生活"管理APP，把每天要做什么、开发项目、个人笔记、花钱、密码，都记在同一个地方。打开首页就能对全局心里有数，各模块各管一摊、互不干扰。

**使用场景（硬性约束）**
- 只在自己电脑（Windows）的浏览器中本地运行
- 所有数据保存在当前电脑硬盘上
- 刷新页面、关闭浏览器、重启电脑后，数据**不丢失**
- 不需要登录、云数据库、部署、手机端；PDF / Markdown 转换使用本机 Python，首次安装依赖需联网，之后完全离线
- 运行方式：双击"启动"文件 → 自动打开浏览器进入APP；数据存在电脑硬盘的一个文件中

**典型用法**
早上双击"启动"打开APP → 首页看全局（今天几件事、项目进度、花钱情况）→ 按需进入各模块记录 → 所有操作即时保存，关掉浏览器即可。

## 2. 整体页面框架和导航结构

- 左侧**竖排导航栏**，列出 7 个模块（当前顺序）
- 右侧为内容区，点击导航切换页面，当前页高亮
- 首页中的摘要卡片可点击，直接跳转到对应模块
- 侧边栏底部有「关闭工作台」按钮

## 3. 首页的内容结构

首页是"一打开就心里有数"的聚合视图。

```
┌──────────────────────────────────────────┐
│  周五 · 9月11日  ·  今天有5件事要做 ✅2     │
├──────────────────────────────────────────┤
│  📋 今日计划   │  💻 开发工作   │  🧰 工具箱 │
│  完成 2/5      │  进行中 3个   │  2 个     │
│  ▶ 去安排      │  今日日志2条   │  📑 PDF转换│
│  待办概要列表…  │  进行中任务…   │  🔧 JSON…│
│  ─────────────│──────────────│────────────│
│  📝 个人笔记   │  💰 账目计划              │
│  3 篇笔记      │  今日支出 ¥35             │
│  最近笔记…     │  本月结余 ¥2,345          │
├──────────────────────────────────────────┤
│  📝 快速备忘                              │
│  [记一句...] [提醒日期] [提醒时间] [+添加] │
│  ⭐ 记得周五交房租  ← 可置顶、可设提醒     │
│  🕐 9月15日 18:00 给妈妈回电话  ← 到期标红 │
└──────────────────────────────────────────┘
```

**内容构成**
- 顶部：今天的日期 + 一句话概括（今天计划几件事、完成几件）
- 5 张摘要卡片，每张显示该模块的关键数字 + **概要内容列表**，**点击卡片或概要项跳转到对应模块**：
  - 今日计划：完成 X/Y、待办概要（前3条未完成）
  - 开发工作：进行中任务数、今日日志条数、进行中任务概要
  - 工具箱：已注册工具数、工具名单
  - 个人笔记：笔记总数、最近笔记标题
  - 账目计划：今日支出、本月结余、最近账目
- 快速备忘：首页直接输入、置顶（⭐）、可设**提醒日期（必填才生效）+ 提醒时间（可选，填时间没填日期默认今天）**、编辑、删除；到期标红

**读写规则**：首页对各模块数据**只读**，唯一可写的是快速备忘。

## 4. 每个模块的用途

- **首页总览**：一打开就能看到全局——今天安排、各模块进度摘要、随手备忘，并作为跳转到各模块的入口。
- **今日计划**：管"今天"——安排每天要做的事，完成打勾，没做完的自动顺延，不会忘。
- **开发工作**：管自己的开发项目——项目、任务、工作日志，每个项目一摊，进度一目了然。
- **工具箱**：常用小工具集合，通过通用注册框架按需扩展（PDF 转换、Markdown 转换、JSON 转换）。
- **个人笔记**：上传 Markdown / 文本笔记，按 H1 自动命名，正文渲染与 H1 目录侧栏，本地保存、随时回看。
- **账目计划**：记每一笔收支，月底知道钱花哪了、结余多少，可设月度预算。
- **数据与设置**：密码箱（加密凭证管理）、工作台外观主题、备份/恢复/清空数据、账目分类管理、关闭工作台。

## 5. 每个模块必要的数据和操作（当前范围）

### 5.1 首页总览

【必要数据】
- 今天的日期
- 各模块汇总数字：今日计划完成 X/Y、开发进行中任务数、今日日志条数、工具箱工具数、笔记总数、今日支出、本月结余
- 各模块概要内容（待办/进行中任务/工具名/最近笔记/最近账目）
- 快速备忘列表（含置顶标记、提醒日期/时间）

【必要操作】
- 点击卡片/概要项跳转到对应模块
- 快速备忘：添加（可带提醒日期/时间）、置顶/取消置顶、编辑、删除、到期标红

### 5.2 今日计划

【必要数据】
- 每条计划：内容、日期、时间段（开始/结束，可选）、是否重要、是否完成、备注、关联文档
- 逾期信息（原定日期、是否顺延到今天）

【必要操作】
- 添加（弹窗表格式：内容/日期/时间段/重要/备注/关联文档）
- 勾选完成（划掉并沉到底部）、取消完成
- 编辑（点开可改全部字段）、删除（弹确认框）
- 标记重要（⭐）
- 日期切换（◀ ▶ 看昨天/明天/任意一天，点日期弹日历，有"回到今天"）
- 筛选（全部 / 今天 / 明天 / 逾期）
- 逾期任务自动顺延到当天，标记"昨·未完成（原X月X日）"
- **拖拽排序**：未完成项可拖拽重排（跨日期也成立）
- **关联文档**：挂网页链接或本地文件/文件夹路径

### 5.3 开发工作

【必要数据】
- 项目：名称、说明、创建时间、远程仓库链接（可选）
- 任务：标题、所属项目、状态（待办/进行中/已完成）、优先级、备注、关联文档、排序序号
- 工作日志：所属项目、日期、干了什么、花了多久

【必要操作】
- 新建 / 编辑 / 删除项目（左栏列表显示"待办X · 进行中X"）
- **项目拖拽排序**
- 查看远程仓库（🔗 按钮，新标签页）
- 新建任务（各栏顶部"＋ 加任务"）
- 移动任务状态：→ 按钮推到下一栏；**拖拽跨栏/同栏重排**
- 任务展开编辑：标题、优先级、备注、关联文档
- **单个任务删除**（确认框）
- 记录工作日志（日期 + 干了啥 + 花了多久），可删除，新在上

### 5.4 工具箱

【必要数据】
- 已注册工具列表（id、名称、图标）

【必要操作】
- 通用注册框架：`registerTool({id, name, icon, render})` 即可新增工具，自动出现在左栏列表与首页摘要卡
- 内置工具：
  - **PDF 转换**：选择 PDF 文件（≥1页）→ 转换为 Word(.doc) / 图片(.png，逐页预览+下载) / Excel(.csv) / PPT(.ppt) / TXT(.txt)，转换结果提供下载
  - **JSON 转换**：粘贴 JSON → 格式化 / 压缩 / 校验（含行列定位）/ 转 CSV / 转 YAML，结果可下载

> 变更记录：原「咨询工作」（客户资料/咨询记录/客户待办/费用）功能已移除。历史数据中 `clients` 字段保留以兼容旧备份文件，不提供任何界面。

### 5.5 个人笔记

【必要数据】
- 每篇笔记：标题、原始 Markdown 文本、创建时间
- 标题取正文首个 H1；没有 H1 时回退为文件名/“未命名笔记”

【必要操作】
- 上传 `.md` / `.markdown` / `.txt` 文件（单文件 ≤ 1MB），读取为文本后保存
- 笔记列表按创建时间倒序，点击切换当前笔记
- 正文安全渲染：标题/列表/代码/表格/引用/链接；HTML 一律转义，危险协议不生成链接
- 右侧（窄屏为上方）显示 H1 目录，点击平滑滚动到对应小节；重复标题自动生成唯一锚点
- 删除笔记（确认框）
- 空状态引导上传第一篇笔记

### 5.6 账目计划

【必要数据】
- 每笔账：支出/收入、金额、分类（带用途：支出/收入/通用）、日期、备注
- 分类列表（默认分类：6 支出类 + 1 收入类；可加自定义分类，默认分类不可删）
- **月度预算**：键=月份，值=金额

【必要操作】
- "＋ 记一笔"弹小窗：选支出/收入 → 金额 → 分类（下拉，支出显示支出类、收入显示收入类）→ 日期（默认今天）→ 备注
- 编辑、删除一笔账
- 筛选明细：全部 / 支出 / 收入 / 按分类
- 月份切换（◀ ▶）
- 顶部四卡：本月收入 / 本月支出 / **本月预算** / 本月结余
- **设置/修改本月预算**（输入 0 取消）；预算进度条（已用/剩余，超支标红）
- 类别条形排行（本月支出按类别，最长排最上）
- **支出分布环形图**（按类别占比）

### 5.7 数据与设置

【必要数据】
- 数据文件信息：位置、大小、上次保存时间
- 密码箱加密配置（salt、迭代次数、密文）
- 工作台外观主题
- 账目分类配置
- 服务控制（关闭工作台）

【必要操作】
- **工作台外观**：13 套主题，默认「桃夭」；另有白色/黄色/蓝色/奶油色 + 国风：中国红/青瓷/墨韵/琉璃/竹青/藕荷/脂玉/天青，选择即生效并自动保存
- **密码箱**：
  - 设置主密码（≥6位）、解锁、锁定、修改主密码
  - 条目（名称/账号/密码密钥/备注）增删改
  - 明文仅存内存，**切换页面自动锁定**
- 备份：弹系统窗口选位置，存一份完整数据副本，文件名带日期（如 WorkLift备份-2026-09-11.json）
- 恢复：选备份文件 → 警告"会覆盖当前所有数据" → 输入"确认"两字才能执行
- 账目分类管理：增删自定义分类（默认分类不可删；被账目使用的自定义分类不可删）
- 清空全部数据：两次确认（弹窗 + 输入"确认"）
- **关闭工作台**：左侧栏底部按钮 → 关闭服务并退出（浏览器阻止时提示手动关闭）

## 6. 首页、各模块之间的关系

- **首页是聚合视图**：读取各模块数据生成摘要，只读展示（唯一可写的是快速备忘）。
- **今日计划是独立模块**：管理每日待办，与开发工作里的任务列表**互不合并**，各自独立存储、各自管理。
- **今日计划内部**：逾期任务自动顺延到新的一天，并标记来源日期（"昨·未完成"），不会默默消失。
- **各模块数据独立存储、互不影响**：修改一个模块不会改动其他模块。
- **跳转关系**：首页卡片/概要项 → 对应模块页面。

## 7. 本地数据文件、备份和恢复要求

- 数据保存在当前电脑硬盘上的一个数据文件中（存放于本APP所在文件夹内，如 `D:\Blogs\WorkLiftApp\data\` 下）。
- **即时保存**：所有操作立即写入数据文件，无需手动点击保存；刷新、关闭浏览器、重启电脑后数据不丢失。
- **备份**：一键把数据文件复制到用户选择的位置，文件名带日期（如 `WorkLift备份-2026-09-11.json`），可随意复制到U盘/网盘。
- **恢复**：选择备份文件 → 弹出警告"会覆盖当前所有数据" → 必须输入"确认"两字才能执行。
- **清空全部数据**：最危险操作，需两次确认（弹窗 + 输入"确认"）。
- 桌面端全程可离线使用（PDF / Markdown 转换依赖本机 Python，首次安装依赖需联网）；数据不离开本机。
