## Why

当前界面为扁平白底风格（纯色背景 + 白色卡片），视觉上缺乏质感与辨识度。用户希望将整个页面升级为"波光玻璃质感"（glassmorphism 磨砂玻璃 + 水面波光闪烁效果），让产品观感更精致、现代，同时明确要求**仅修改外观，不改变任何功能**。

## What Changes

- 全局页面背景：由纯色 `#f7f8fa` 改为柔和的波光渐变背景（水蓝色系渐变 + 流动的波光高光动画）。
- 容器质感：侧边栏、卡片、弹窗、Toast 等容器改为磨砂玻璃质感（半透明填充 + 背景模糊 + 细腻边框高光 + 柔和阴影）。
- 控件质感：按钮、输入框、标签页、徽章、空状态等控件统一融入玻璃质感，保持原有语义色（主色/绿/橙/红）不变。
- 波光动画：为背景增加缓慢流动的波光效果，并遵循 `prefers-reduced-motion` 降级为静态。
- 交互反馈：hover / active / focus 状态保留，仅调整视觉呈现（如玻璃亮度、高光位置），不改变触发方式与行为。
- 布局与结构：**不修改**任何 DOM 结构、元素 ID/class 命名、路由、交互逻辑、数据流。仅变更样式表及必要的纯视觉装饰层（优先使用 CSS 伪元素，避免改动 HTML）。

## Capabilities

### New Capabilities
- `visual/glass-shimmer`: 定义 WorkLift 的波光玻璃质感视觉主题——背景、容器、控件、动画、可访问性降级等外观层面的可观察行为。

## Impact

- `public/css/style.css` — 主要修改文件（全局变量、背景、容器、控件样式）。
- `public/index.html` — 仅在纯 CSS 无法实现背景装饰时才需要添加装饰层（优先避免改动）。
- `public/js/**` — 不改动；仅检查页面内联样式是否会与玻璃质感冲突（已知 consult.js 有一处内联颜色，无需变更）。
- `server.js` / 数据层 / API — 无影响。
- 依赖 — 无新增依赖，无构建工具变更。
